# CeraVe SEO Strategy & Content Campaign

Marketing case study by Cherry. Static site: no build step, no dependencies.

```
cerave-seo-portfolio/
├── index.html      page content
├── styles.css      design
├── script.js       nav, filters, image viewer
└── assets/         cropped screenshots from the project
```

## Preview locally

Open `index.html` in a browser, or from this folder run:

```
python -m http.server 8000
```

then visit http://localhost:8000

## Publish on GitHub Pages

1. Create a public repository and upload everything in this folder (including `assets/`).
2. Settings → Pages → Deploy from a branch → `main` / `(root)` → Save.
3. The site is live at `https://<username>.github.io/<repository>/`.
